# Offline Static Mode

All UI behavior can be demonstrated with feature-owned mock data and static states until the Node.js API is connected. Static prices, metrics, referral data, financial values, and statuses are illustrative only. They must be replaced by backend-provided data through the relevant feature service; no client value is authoritative.

External values still required for production are official Frenzone assets, approved legal text, mobile store URLs, deep-link provider configuration, payment configuration, and backend contracts.
